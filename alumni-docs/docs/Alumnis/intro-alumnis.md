# Servicio de Alumnis

Este servicio permite la exploración de todos las entradas de alumnis a todos los usuarios, con una función de filtros avanzada por **barra de búsqueda**, filtro por **generación de ingreso**, **generación de egreso**, **título de pregrado**, **postgrado**, **sexo** y **fallecimiento**.

Funciones más restrictivas como la creación, edición y borrado de Usuarios se detallan más adelante.
