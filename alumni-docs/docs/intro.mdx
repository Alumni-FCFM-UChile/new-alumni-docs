# Documentación de la plataforma de Alumnis de la FCFM

A continuación se dará una breve descripción de en que consiste la plataforma, que tipos de usuarios tiene y que puede hacer cada uno de ellos.

## Descripción de la plataforma

Esta plataforma es una aplicación web de usuarios que permite la gestión de la información de exalumnos recopilada por la Dirección de vinculación externa. Particularmente, se puede visualizar, crear nuevas entradas de información (alumnis), editar y borrar.

## Tipos de usuario

Esta plataforma cuenta con un sistema de usuarios, usuarios que se clasifican en tres tipos: **invitados, normales y administradores**. Los **invitados** tienen permisos de **visualización y descarga** de alumnis solamente. Los usuarios **normales** adicionalmente a los permisos que tienen los invitados tienen permisos de **edición y creación** de alumnis. Los **administradores** tienen permiso total, pueden **editar, crear y borrar** alumnis.
