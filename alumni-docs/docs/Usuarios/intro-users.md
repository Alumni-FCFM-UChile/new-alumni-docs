# Servicio de Usuarios

Solamente usuarios de tipo **administrador** pueden acceder a este servicio. Si en tu barra de navegación (barra superior) no hay una pestaña de usuarios es porque no tienes los permisos para acceder a ella. Sin embargo, todos los usuarios pueden editar su propia contraseña e información.

La tabla de usuarios tiene considerablemente menos columnas/campos, estos siendo: **id**, **Nombre de usuario**, **Correo de contacto** y **Tipo de usuario**.
